INTRODUCTION

The aim of this project is to explore how likely an NFL (National Football League) team is going to win a game given the current game statistics. Specifically, this project examines the influences of variables such as field position, time remaining, and score difference on the game’s outcome throughout the game. Additionaly, our model will take into account the offensive and defensive team performance based on historical patterns of how each respective teams perform in specific game situations. Theses variables are the foundations for training a machine learning model that estimates the win probability on a play-by-play basis during an NFL game.

METHODS

Data Collection

The dataset was extracted using the ESPN Public API. To start, the API was used to collect all NFL games from the 2022 season, providing a dataset containing 336 games with 3 variables.

Games Dataset:

  • id: Game ID number

  • name: Game name

  • date: Game date

Next, a second ESPN Public API was used to retrieve play-by-play data that occurred in each game of the 2022 season. This produced a dataset of 57,547 observations (or single plays) with 13 variables including several game statistics.

Plays Dataset:

  • gid: Game ID number

  • pid: Play ID number

  • play_action: Description of play

  • quarter: Quarter in which the play occurred

  • time_remaining: Time remaining in the current quarter (in seconds)

  • down: Down in which play was done

  • yards_to_go: Yards needed to get a first down

  • yardsToEndzone: Yards needed to get a touchdown/the endzone

  • yards_gained: Yards gained on play

  • home_score: Home team’s current score

  • away_score: Away’s team current score

  • offense_team: Offensive team’s ID number

  • defense_team: Defensive team’s ID number

Data Cleaning & Wrangling

Based on the summary table of missing data, we observe that most variables in the plays dataset don’t have any missing values. The only variables with missing vales are offense_team and defense_team.

Further investigation of these observations shows that these values are missing when the play occurred at the start or end of a quarter or game (indicated by variable play_action). Since these plays don’t represent standard plays, they are not relevant for our model and thus are filtered out.

Moreover, after examining the summary statistics table, we see that all variables are within the reasonable ranges:

  • home_score and away_score are positive (minimums are 0)

  • yards_gained has a range within -109 and 109 yards, which is the maximum length of a football field including the end zones

  • time_remaining between 0 and 900 which is 4 quarters of 15 minutes

  • yards_to_go and yardsToEndzone are positive and under 100 yards, reflecting the maximum possible distance of a football field

However, the summary statistics table also show a minimum values of 0 for variables: down and quarter. After examining these observations, we see that these plays corresponds to kickoffs or start of a game. Because these events don’t represent standard play, we keep entries with quarter 1,2,3,4 and 5 (representing the 4 quarters of a standard NFL game and overtime), as well as downs 1,2,3,4 (representing offensive downs)

After filtering out irrelevant data, our dataset contains 52,410 meaningful plays across all games.

Feature Engineering

In order to better represent the state of the game, two additional variables were engineered from existing data:

  • gametime_remaining: Time remaining in the game (in seconds)

    • This was calculated by taking the number of quarters remaining multiplied by 900 seconds (which is 15 minutes) and adding the remaining time in the current quarter.
    • And set it to NULL for overtime plays

  • score_diff: Score Difference between home and away team (relative to the home team)

    • This was measured by the difference between the home team’s score and away team’s score at that time of play

Exploratory Data Analysis

This stacked bar graph displays the number of plays as well as the proportion of downs across each quarter. We can see that there are more plays occurring in second and fourth quarter. Besides that, first and second down occurs more frequent compared to third and fourth down. Notice how there is more fourth down played in the fourth quarter compared to other quarters suggesting increased risk-taking drives attempted by teams. Another thing to highlight, is the low count in plays for 5th quarter as overtime don’t happen often in NFL games.

The distribution of time remaining within each quarter is balanced with plays occurring throughout the duration of the game. This suggests that plays are not are not concentrated in a certain time of the quarter and that our data is not skewed.

Field position values are distributed across the field with more plays occurring at approximately 75 yards away from the end zone where most drives often begin.

The association between the score difference and game time remaining seems to have a correlation where as game time decreases, the score differences tend to increase, reflecting the fact that games often become more decisive towards the end.

SUMMARY

The exploratory analysis highlights several patterns in the data that are relevant for predicting game outcomes. The variables describe immediate context of each play and together it captures the overall game state at any point of time in a game.

In the final stage of this project, a machine learning model will be trained using the plays dataset. The variables selected will be used as input features to estimate the probability that a team wins the game given the current game state, as well as the difference in the offense and defense team performance. Then, model will be evaluated using a test dataset which will be the 2023 NFL season games play by play dataset. The model will be assessed using an accuracy score.

The results of the model will be illustrated on an interactive website, where win probability graphs are updated after each play. Additional visualizations such as possession time, number of first downs achieved, and a updated game stats table will also be displayed to provide further analysis of game progression.
